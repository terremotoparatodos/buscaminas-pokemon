# Audio

Efectos originales de estilo arcade, generados para este proyecto:

| Archivo          | Cuándo suena                        |
|------------------|-------------------------------------|
| `correct.wav`    | al acertar un Pokémon               |
| `bomb.wav`       | al tocar una bomba                  |
| `perfect.wav`    | ronda perfecta (8/8)                |
| `next-round.wav` | al pasar a la ronda siguiente       |

Las rutas se cambian en `js/config.js` (`audio`). El juego conserva un fallback silencioso si algún archivo no carga.
Mute: botón 🔊 del panel o tecla `M`.
